═══════════════════════════════════════════════════════════════
 🚀  ЗАПУСК ПРИЛОЖЕНИЙ
═══════════════════════════════════════════════════════════════

Mod+Return            — Терминал (Alacritty)
Mod+B                 — Браузер (Firefox)
Mod+Ctrl+Left         — Лаунчер приложений (ahoma msg panel-toggle launcher)
Mod+S                 — Центр управления Noctalia
Mod+Shift+S           — Настройки Noctalia
Mod+Shift+Return      — Выбор обоев
Mod+E                 — Файловый менеджер (Nautilus)
Mod+Shift+Q           — Меню сессии (выход/перезагрузка)
Mod+Alt+L             — Блокировка экрана
Mod+O                 — Обзор рабочих столов

═══════════════════════════════════════════════════════════════
 🪟  УПРАВЛЕНИЕ ОКНАМИ
═══════════════════════════════════════════════════════════════

Mod+Q                 — Закрыть окно
Mod+T                 — Плавающий / тингл режим
Mod+F                 — Максимизировать колонку
Mod+Shift+F           — Полноэкранный режим
Mod+W                 — Табличный вид колонки
Mod+M                 — Растянуть окно на весь экран

Mod+R                 — Переключить ширину колонки (33% / 50% / 66%)
Mod+Shift+R           — Переключить высоту окна
Mod+Ctrl+R            — Сбросить высоту окна
Mod+C                 — Центрировать колонку
Mod+Ctrl+C            — Центрировать все видимые колонки

Mod+Minus             — Уменьшить ширину колонки на 10%
Mod+Equal             — Увеличить ширину колонки на 10%
Mod+Shift+Minus       — Уменьшить высоту окна на 10%
Mod+Shift+Equal       — Увеличить высоту окна на 10%

Mod+Comma             — Втянуть окно в колонку
Mod+Period            — Вытолкнуть окно из колонки
Mod+[                 — Поглотить/вытолкнуть окно влево
Mod+]                 — Поглотить/вытолкнуть окно вправо

═══════════════════════════════════════════════════════════════
 🧭  НАВИГАЦИЯ ФОКУСА
═══════════════════════════════════════════════════════════════

Mod+H  / Mod+←        — Фокус влево
Mod+L  / Mod+→        — Фокус вправо
Mod+K  / Mod+↑        — Фокус вверх
Mod+J  / Mod+↓        — Фокус вниз
Mod+Home              — Фокус на первую колонку
Mod+End               — Фокус на последнюю колонку

═══════════════════════════════════════════════════════════════
 📦  ПЕРЕМЕЩЕНИЕ ОКОН
═══════════════════════════════════════════════════════════════

Mod+Ctrl+H / Mod+Ctrl+←  — Колонку влево
Mod+Ctrl+L / Mod+Ctrl+→  — Колонку вправо
Mod+Ctrl+K / Mod+Ctrl+↑  — Окно вверх
Mod+Ctrl+J / Mod+Ctrl+↓  — Окно вниз
Mod+Ctrl+Home            — Колонку в начало
Mod+Ctrl+End             — Колонку в конец

═══════════════════════════════════════════════════════════════
 🖥️  МОНИТОРЫ
═══════════════════════════════════════════════════════════════

Mod+Shift+←           — Фокус на монитор слева
Mod+Shift+→           — Фокус на монитор справа
Mod+Shift+↑           — Фокус на монитор сверху
Mod+Shift+↓           — Фокус на монитор снизу

Mod+Shift+Ctrl+←      — Колонку на монитор слева
Mod+Shift+Ctrl+→      — Колонку на монитор справа
Mod+Shift+Ctrl+↑      — Колонку на монитор сверху
Mod+Shift+Ctrl+↓      — Колонку на монитор снизу

Mod+Shift+V           — Переключить фокус плавающий/тилинг

═══════════════════════════════════════════════════════════════
 🗂️  РАБОЧИЕ СТОЛЫ
═══════════════════════════════════════════════════════════════

Mod+1 … Mod+9         — Перейти на рабочий стол 1–9
Mod+Ctrl+1 … Mod+Ctrl+9 — Переместить колонку на рабочий стол 1–9
Mod+TAB               — Предыдущий рабочий стол

Mod+Scroll↑ / Scroll↓      — Переключить рабочий стол
Mod+Ctrl+Scroll↑ / Scroll↓ — Переместить колонку на другой рабочий стол
Mod+Scroll← / Scroll→      — Фокус колонки влево/вправо
Mod+Shift+Scroll↑ / Scroll↓ — Фокус колонки влево/вправо (альт.)
